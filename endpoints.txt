1) CHAT LIVRE (FREE MODE)
================================================================================

URL: POST /free-mode/
Autenticação: REQUERIDA (Bearer JWT)

DESCRIÇÃO:
Endpoint de conversa pedagógica com dois comportamentos automáticos:

- study_plan: quando a pergunta tem match forte com disciplinas/conteúdos do banco,
  a API responde ensinando e também recomenda trilha.

- pedagogical_support: quando a mensagem é mais conversacional ou sem match forte,
  a API responde de forma acolhedora/didática, sem gerar trilha.

Observação importante:
- Fontes do tipo VIDEO são excluídas das recomendações.


REQUISIÇÃO
================================================================================

Método: POST
URL: http://localhost:8000/free-mode/?question=<pergunta>

Headers obrigatórios:
- Authorization: Bearer <token_jwt>

Query params:
- question (string, obrigatório)

Exemplo cURL:
curl -X POST "http://localhost:8000/free-mode/?question=Bem-vindo%20a%20casa%20tem%20crase%20no%20a" \
  -H "Authorization: Bearer seu_token_jwt"

Exemplo Frontend (fetch):
const token = "seu_token_jwt";
const question = "Bem-vindo a casa tem crase no a?";

const res = await fetch(
  `http://localhost:8000/free-mode/?question=${encodeURIComponent(question)}`,
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${token}`,
      "Content-Type": "application/json"
    }
  }
);

const data = await res.json();

REGRAS DE USO NO FRONTEND
================================================================================

1. Sempre ler conversation_mode.

2. Se conversation_mode = study_plan:
   - mostrar teaching
   - mostrar trilha
   - mostrar recommended_studies

3. Se conversation_mode = pedagogical_support:
   - mostrar apenas teaching
   - ocultar trilha e recomendações

4. Para UX melhor:
   - mantenha mensagens em formato de conversa
   - mostre trilha só quando vier conteúdo em trail.trail


ERROS COMUNS
================================================================================

400 Bad Request
- Quando question vier vazio.
Exemplo:
{
  "detail": "O parâmetro 'question' não pode ser vazio."
}

401 Unauthorized
- Token ausente/inválido/expirado.

500 Internal Server Error
- Falha do Ollama ou retorno inválido de JSON.


FLUXO INTERNO (RESUMO)
================================================================================

1. Valida JWT e question.
2. Classifica pela base interna (disciplinas + conteúdos + fontes não-vídeo).
3. Se recommendation_eligible = true:
   - gera teaching + trilha + recomendações.
4. Se recommendation_eligible = false:
   - gera apenas apoio pedagógico conversacional.
