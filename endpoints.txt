=============================================================
  ENDPOINTS DE CHAT — DOCUMENTAÇÃO PARA INTEGRAÇÃO FRONTEND
=============================================================

BASE URL: http://localhost:8000   (ou sua URL de produção)

AUTENTICAÇÃO: Todos os endpoints exigem o header:
  Authorization: Bearer <access_token>

================================================================
1. CRIAR NOVO CHAT
================================================================
Método:  POST /chats
Auth:    Sim

Request Body (JSON):
  {
    "name": "Matemática - Revisão",     // string, obrigatório
    "mode": "LIVRE"                      // enum, opcional (padrão: "LIVRE")
  }

Valores válidos para "mode":
  "REFORÇO" | "ENEM" | "CONCURSO" | "LIVRE"

Response 201 (JSON):
  {
    "id": 42,
    "name": "Matemática - Revisão",
    "mode": "LIVRE",
    "created_at": "2026-05-26T10:00:00",
    "last_interaction": "2026-05-26T10:00:00",
    "is_active": true,
    "last_message": null
  }

Exemplo Axios:
  const res = await axios.post('/chats', { name: 'Revisão', mode: 'ENEM' });
  const chat = res.data; // { id, name, mode, ... }

3. BUSCAR DETALHES DE UM CHAT (COM MENSAGENS)
================================================================
Método:  GET /chats/{chat_id}
Auth:    Sim

URL Params:
  chat_id  — número inteiro (ID do chat)

Response 200 (JSON):
  {
    "id": 42,
    "name": "Matemática - Revisão",
    "mode": "ENEM",
    "created_at": "2026-05-26T10:00:00",
    "last_interaction": "2026-05-26T11:30:00",
    "messages": [
      {
        "id": 1,
        "sender": "USER",
        "content": "Qual é a fórmula de Bhaskara?",
        "sent_at": "2026-05-26T10:05:00"
      },
      {
        "id": 2,
        "sender": "IA",
        "content": "A fórmula de Bhaskara é...",
        "sent_at": "2026-05-26T10:05:03"
      }
    ]
  }

Valores possíveis para "sender": "USER" | "IA"

Exemplo Axios:
  const res = await axios.get(`/chats/${chatId}`);
  const { messages } = res.data;

5. ENVIAR MENSAGEM AO TUTOR IA (STREAMING — SSE)
================================================================
Método:  POST /chat-tutor/
Auth:    Sim
Content-Type: application/json
Resposta: text/event-stream (Server-Sent Events)

Request Body (JSON):
  {
    "messages": [                        // obrigatório — histórico completo da conversa
      { "role": "user",      "content": "Explique logaritmos" },
      { "role": "assistant", "content": "Logaritmos são..." },
      { "role": "user",      "content": "Pode dar um exemplo?" }
    ],
    "mode":        "responde",           // opcional (padrão: "responde")
    "chat_id":     42,                   // opcional — ID do chat para salvar histórico
    "content_id":  null,                 // opcional — ID de conteúdo relacionado
    "exam_id":     null,                 // opcional — ID de prova relacionada
    "question_id": null                  // opcional — ID de questão relacionada
  }

A IA responde via streaming SSE. Cada evento chega como texto no formato:
  data: <texto_parcial>\n\n

O stream encerra com:
  data: [DONE]\n\n

Em caso de erro no servidor, a IA responde com a mensagem:
  "Desculpe, ocorreu um erro ao gerar a resposta."

----------------------------------------------------------------
Como consumir o stream com Axios + ReadableStream no React:
----------------------------------------------------------------

  const response = await fetch('/chat-tutor/', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`,
    },
    body: JSON.stringify({
      messages,
      mode: 'responde',
      chat_id: chatId,
    }),
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let fullText = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = line.replace('data: ', '');
        if (data === '[DONE]') break;
        fullText += data;
        setAiMessage(fullText); // atualiza estado do React incrementalmente
      }
    }
  }

NOTA: Para streaming, use fetch nativo ou EventSource, não axios.get/post
      diretamente (axios não suporta streaming incremental de SSE facilmente).

6. SESSÃO DE PROGRESSO — INICIAR
================================================================
Método:  POST /progress/session/start/{chat_id}
Auth:    Sim

URL Params:
  chat_id  — número inteiro

Response 200 (JSON):

7. SESSÃO DE PROGRESSO — ENCERRAR
================================================================
Método:  POST /progress/session/end/{chat_id}
Auth:    Sim

URL Params:
  chat_id  — número inteiro

Response 200 (JSON):
  {
    "message": "Sessão encerrada"
  }

Exemplo Axios:
  await axios.post(`/progress/session/end/${chatId}`);


================================================================
FLUXO TÍPICO DE UMA CONVERSA NO FRONTEND
================================================================

1. Criar chat (POST /chats) → guarda chat.id
2. Iniciar sessão (POST /progress/session/start/{chat_id})
3. Montar array "messages" com todo o histórico (role: user/assistant)
4. Enviar mensagem + receber stream (POST /chat-tutor/) via fetch
5. Exibir texto incrementalmente conforme chunks chegam
6. Ao fechar ou sair: encerrar sessão (POST /progress/session/end/{chat_id})

Para reabrir um chat existente:
  → GET /chats/{chat_id} retorna todas as mensagens salvas
  → Mapear sender "USER" → role "user" e "IA" → role "assistant"
    antes de enviar ao endpoint /chat-tutor/


================================================================
RESPOSTAS DE ERRO COMUNS
================================================================

401 Unauthorized  — token inválido, expirado ou ausente
403 Forbidden     — chat pertence a outro usuário
404 Not Found     — chat_id inexistente
422 Unprocessable — body malformado ou campo obrigatório ausente
