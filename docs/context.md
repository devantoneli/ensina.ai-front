# Ensina Aí — Contexto do Projeto

## Visão Geral

O **Ensina Aí** é um sistema de **Inteligência Artificial voltado para auxílio no aprendizado**, desenvolvido como **Trabalho de Conclusão de Curso (TCC)** do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo do projeto é criar um **agente educacional inteligente** que auxilie estudantes no processo de aprendizagem de forma ativa.

Diferente de assistentes comuns, o sistema **não fornece respostas diretas imediatamente**, mas conduz o estudante até a solução através de explicações e perguntas.

O sistema utiliza princípios de aprendizagem baseados em:

* ensino progressivo
* estímulo ao raciocínio
* adaptação ao nível do estudante
* uso de fontes de conhecimento confiáveis

---

## Problema Abordado

Atualmente muitos estudantes utilizam sistemas de IA para resolver exercícios ou trabalhos escolares.

Esses sistemas muitas vezes:

* fornecem respostas prontas
* utilizam fontes não verificadas
* incentivam aprendizagem passiva

O **Ensina Aí** busca resolver esse problema transformando a IA em um **agente de orientação educacional**.

---

## Objetivo do Sistema

Criar um agente de Inteligência Artificial capaz de:

* ensinar conceitos antes de responder
* estimular pensamento crítico
* utilizar fontes de conhecimento verificadas
* adaptar respostas ao perfil do estudante

A IA deve atuar como **guia de aprendizado**, não como substituto do professor.

---

## Perfis de Usuário

### Student (Estudante)

Usuário principal da plataforma.

Permissões:

* criar conta
* realizar login
* utilizar chat com IA
* realizar simulados
* acessar histórico de conversas
* editar ou excluir sua conta

Restrições:

* não pode acessar dados de outros usuários
* não pode gerenciar conteúdos do sistema

---

### Admin (Administrador)

Usuário responsável pela gestão do sistema.

Permissões:

* gerenciar fontes de conhecimento
* adicionar conteúdos educacionais
* validar fontes de informação
* visualizar métricas de uso
* configurar limites do sistema

---

## Funcionalidades Principais

### Chat Inteligente

* conversa em tempo real com IA
* histórico persistido
* respostas adaptadas ao perfil do usuário
* estratégia de ensino socrático

---

### Simulados

* geração de provas
* armazenamento de respostas
* cálculo de desempenho
* identificação de dificuldades do estudante

---

### Sistema de Conteúdo

Administradores podem inserir:

* artigos
* vídeos
* links educacionais
* materiais didáticos

Esses conteúdos servem como base de conhecimento da IA.

---

## Comportamento Esperado da IA

O agente educacional deve:

1. identificar o nível do estudante
2. verificar quais conceitos ele domina
3. ensinar conceitos necessários
4. estimular raciocínio através de perguntas
5. corrigir respostas incorretas
6. evitar fornecer respostas diretas inicialmente
7. utilizar fontes confiáveis cadastradas no sistema
